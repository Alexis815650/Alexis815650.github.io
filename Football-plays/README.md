# Flag Football Playbook Website (VS Code starter)

## Open this project
1. Extract this ZIP.
2. In VS Code choose **File → Open Folder...**
3. Select the extracted `football_playbook_vs_code` folder (the folder containing `index.html`).
4. Install the **Live Server** extension if needed.
5. Open `index.html`, right-click the editor, and choose **Open with Live Server**.

## Project files
- `index.html` — page structure
- `style.css` — styling and mobile layout
- `app.js` — website quiz and play-drawing logic
- `images/` — the original images from the uploaded OneDrive ZIP

## Important
The images are included in `images/`, but the starter website still draws some quiz diagrams as SVG placeholders. They are not all wired up to the original photos yet. The uploaded Code.org source uses App Lab functions such as `onEvent`, `setProperty`, and `setScreen`; those cannot be pasted straight into a regular website. We need to convert the relevant logic into normal browser JavaScript and connect the images using paths like `images/54.jpg`.

Keep the filenames as they are. If an image doesn't display later, check spelling, spaces, and capitalization.
